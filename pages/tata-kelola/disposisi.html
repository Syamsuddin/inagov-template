Usulan pengadaan server & storage pusat data 2027

Diajukan Rahmat Hidayat, S.T. (Kasi Infrastruktur TIK) · 17 Sep 2026 · nilai usulan Rp 1.850.000.000
Lihat jejak audit
Tenggat tindakan hari ini pukul 15.00 WITA agar usulan masuk batas akhir input RKA di SIPD. Setelah tenggat, berkas dieskalasi otomatis ke Kepala Dinas.
PerihalUsulan pengadaan 2 unit server rack, 1 unit storage 100 TB, dan UPS untuk pusat data Diskominfo pada APBD 2027. Program / kegiatanPengelolaan e-Government · Penyelenggaraan Sistem Jaringan Intra Pemda (2.16.03.2.02) Nilai usulanRp 1.850.000.000 (belanja modal) DasarRekomendasi audit infrastruktur 2026: kapasitas storage 91%, server produksi berusia 7 tahun Alur persetujuanKasi → Kabid Aptika → Sekretaris Dinas → Kepala Dinas

Dengan hormat, sehubungan dengan hasil audit infrastruktur pusat data tahun 2026 yang menunjukkan kapasitas penyimpanan telah mencapai 91% dan dua server produksi telah melewati masa pakai teknis, bersama ini diusulkan pengadaan sebagaimana rincian terlampir. Spesifikasi telah mengacu pada standar Arsitektur SPBE Nasional dan katalog elektronik LKPP.
